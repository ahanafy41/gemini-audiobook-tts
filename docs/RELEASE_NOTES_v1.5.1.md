# Gemini Audiobook TTS v1.5.1 (Android & Desktop Suite)

تحديث استقراري هام يتضمن تحصينات معمارية لحل مشكلة تعثر الخادم العابر وتوقف الصوت.

### ما الجديد في الإصدار v1.5.1:
1. **علاج عطل توقف توليد الصوت (السبب: OTHER)**:
   - تصنيف انقطاعات الصوت العابرة وأخطاء السيرفر (500..599) كأخطاء قابلة للإعادة التلقائية.
   - تدوير ذكي وفوري بين مفاتيح الـ API المسجلة دون إيقاف تحويل الكتاب.
   - تطبيق خوارزمية التراجع الزمني التصاعدي (Exponential Backoff: 1.5s ثم 3s) لإنعاش دفق الصوت بسلاسة.

2. **الانقسام التكيفي للمقاطع (Adaptive Sub-Chunk Bisection)**:
   - ضبط سقف تقطيع النصوص إلى 3,800 حرف لمنع الـ Timeout الداخلي لخوادم Gemini TTS.
   - شطر المقاطع الطويلة المتعثرة تلقائياً إلى نصفين ودمج الصوت الناتج بشفافية كاملة دون أي تدخل من المستخدم.

3. **تحسين التحديث التلقائي المباشر (In-App OTA Updates)**:
   - إشعار صوتي فوري عند توفر الإصدارات الجديدة وقابلية التحديث والتثبيت بضغطة زر واحدة لمستخدمي قارئات الشاشة (TalkBack و Jieshuo).
